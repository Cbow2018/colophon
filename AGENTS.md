# AGENTS.md

## Agent skills

### Issue tracker

Public issues and specs for this repo live as **GitHub issues** in `Cbow2018/colophon`, driven by the `gh` CLI: that is the tracker contributors can see, file against and be answered in. **Linear is the maintainer's private todo list** — workspace `cbow`, team **Athenaeus**, project **Colophon**, identifiers like `CBO-36`, reached with the `mcp__linear__*` tools. Nothing in Linear is public and nothing is mirrored between the two, so an agent reading Linear is reading planning notes, not the issue tracker. See `docs/agents/issue-tracker.md`.

### Triage labels

Default vocabulary — `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` plus `docs/adr/` at the repo root. See `docs/agents/domain.md`.
